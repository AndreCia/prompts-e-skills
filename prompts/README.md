# Prompts

Todos os prompts da biblioteca, separados por finalidade. Abra a categoria que
interessa e copie direto do bloco de código.

| [Imagens](imagens/) | Prompts para geração de imagem: fotografia, retrato, ilustração, arte e material gráfico | 2 |
| [Negócios](negocios/) | Prompts para pensar o negócio: análise, estratégia, posicionamento e pesquisa de mercado | 2 |
| [Produtividade](produtividade/) | Prompts para ganhar tempo: resumos, organização, apoio a estudo e leitura | 1 |
