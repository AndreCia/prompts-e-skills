# Prompts e Skills

**Biblioteca gratuita de prompts, skills e ferramentas de IA, em português.**

Material testado no dia a dia, organizado por finalidade e atualizado com
frequência. Nada de lista genérica traduzida do inglês.

> Material novo toda semana no Instagram: [@ciaandre](https://instagram.com/ciaandre)

---

## Como usar

Você não precisa saber programar nem instalar nada.

1. Escolha uma categoria na tabela abaixo.
2. Abra o prompt que interessa.
3. Clique no ícone de copiar no canto do bloco de código.
4. Cole na sua IA preferida e troque o que estiver `ENTRE_CHAVES`.

Se preferir baixar tudo de uma vez, use o botão verde **Code** no topo desta
página e depois **Download ZIP**.

Primeira vez usando prompts? Comece pelo guia
[Como usar os prompts](guias/como-usar-os-prompts.md).

## Skills

Skills são automações que ensinam o Claude Code a executar uma tarefa inteira
sozinho, com o seu padrão. Instalação em um minuto:
[Como instalar skills](guias/como-instalar-skills.md).
