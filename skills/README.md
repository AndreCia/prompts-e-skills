# Skills

Skill é uma automação que ensina o Claude Code a executar uma tarefa inteira
com o seu padrão, sem você precisar explicar tudo de novo a cada vez. Você
digita uma frase e ele executa o procedimento completo.

Instalação em um minuto:
[Como instalar skills](../guias/como-instalar-skills.md).

| Skill | O que faz |
|---|---|
| [Organizador de links](exemplo-organizador-de-links/) | Recebe links soltos, classifica por tema e devolve uma lista organizada em Markdown |
