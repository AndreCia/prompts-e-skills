# Organizador de links

Você joga uma pilha de links soltos e recebe de volta uma lista organizada por
tema, com uma descrição real de cada um, pronta para publicar.

## Instalação

1. Baixe a pasta `exemplo-organizador-de-links`.
2. Copie ela para `~/.claude/skills/` no seu computador.
3. Renomeie a pasta para `organizador-de-links`.
4. Abra o Claude Code e mande os links.

O passo a passo completo, com print, está em
[Como instalar skills](../../guias/como-instalar-skills.md).

## Como usar

Cole os links e peça:

```
organiza esses links pra mim
```

Não precisa dizer mais nada. A skill dispara sozinha ao reconhecer o pedido.

## Exemplo de saída

### Ferramentas de imagem

| Link | O que é | Para quem serve |
|---|---|---|
| exemplo.com | Gerador de imagem por IA, gratuito até 50 por mês | Quem está começando e não quer assinar nada |

### Links com problema

- `outro-exemplo.com`: exige login, não foi possível verificar.
